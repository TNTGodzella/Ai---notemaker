# 🧠 AI Notes Maker

AI Notes Maker is a **personal full-stack project** that helps users create, manage, and enhance notes using **AI**.  
It uses **GROQ AI models** to provide fast **summarization** and **grammar correction**, making note-taking smarter and more productive.

---

## ✨ Features

- 📝 Create notes  
- ✏️ Edit and update notes  
- ❌ Delete notes  
- 📂 View and manage all notes in one place  
- 📌 AI-powered text summarization  
- ✅ Grammar and language correction using AI  

---

## 🖥️ Screens / Workflow

1. Create or edit a note  
2. Save the note to the database  
3. Apply AI features:
   - Generate summary
   - Fix grammar
4. Manage notes (edit or delete anytime)

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **AI Engine:** GROQ AI (LLM-based text processing)
